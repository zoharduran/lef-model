# The LEF Model — How the Moon Really Formed

Website: **https://lef-model.com**

The LEF (Lunar Elevation & Fission) model is a paper series by Zohar Duran proposing that the Moon was built from the Earth's own material and released at the corotation radius, rather than formed in a giant impact.

- Papers in ten languages: https://lef-model.com/papers.html
- All papers (Zenodo, all versions): https://doi.org/10.5281/zenodo.22743615
- The book on Amazon (Kindle, paperback, hardcover): https://www.amazon.com/dp/B0HS1WY52Q

This repository holds the source of the website.
