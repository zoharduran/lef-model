LEF MODEL · 第 21 章

第 21 章：太陽系の衛星の法則——誕生様式の物差し、ポンプの原理、大気のふた

論文 11——11. 衛星の誕生：衛星の誕生のための一つの仕組み（A–B 部：誕生の物差し、ポンプとふたの原理、分化の段階、13 の点検の手順）にもとづく

01 · THE MYSTERY

謎：一つの物理法則が、太陽系のすべての衛星の誕生を説明するのか——地球から冥王星まで？

これまでの章で、地球が洋梨の先端で月をつくったこと（第 1〜9 章）、そして火星がとがったふくらみの頂上の火山からフォボスとダイモスを放出したこと（第 19〜20 章）を見ました。論文 11 で LEF モデルは、この二つの例を「衛星の法則」へと一般化します——太陽系のあらゆる惑星と準惑星に成り立つ一様な仕組みです：

  1. なぜ衛星は大きさと組成でこれほどちがうのか？地球の月は乾いていて、親に対して巨大です（地球の質量の 1.2%）。巨大惑星（木星、土星、天王星、海王星）の衛星はごく小さく（0.01%〜0.02%）、水と氷に富んでいます。一方、カロンは冥王星とカロンの系の質量の 11% を占めているのです！
  2. なぜ衛星の密度は太陽からの距離とともに下がり——そして天王星でまた跳ね上がるのか？地球の月の密度は 3,344 kg/m³、木星のガリレオ衛星は ~ 2,600 kg/m³、土星の衛星は ~ 1,350 kg/m³——ところがもっと遠い天王星では、密度は 1,505 kg/m³ へと上がり戻るのです！
  3. なぜ五つの惑星（火星、木星、土星、天王星、海王星）では、小さな衛星が共回転線の両側にいるのか？そしてなぜ水星と金星には衛星がまったく残らなかったのか？
02 · AN IMAGE

イメージ：共回転線の距離の物差し、腕を引きよせるスケーター、そして泡のふたをもつ二つのスープの鍋

四つの手にとれるイメージが、太陽系全体での衛星の誕生の物理を説明します：

  • コートが外へふくらむあいだに腕を引きよせるアイススケーター（内で縮み外でふくらむ、A.5）：惑星の分化は、どうやって共回転線を表面に近づけるのでしょう？角運動量を失わずに一様にふくらむ天体は遅くなり、共回転線を遠ざけるでしょう。しかし分化は内と外で逆向きの過程です：重い核（質量の大部分をもつ）は沈んで内へ縮み、腕を引きよせるスケーターのように自転を速め、一方で軽い水と揮発性物質は上へ押しやられて、自転をほとんど遅くせずに外側の外層をふくらませるのです。だから共回転線の相対的な距離は x∝(k2R)1/3x \propto (k^2 R)^{1/3} にしたがって縮み、表面と出会うのです！
  • 「流体力学的なポンプ」（ポンプの原理、A.4）：重い物質の核への沈みこみは、静水圧によって、水と軽いケイ酸塩を放出の開口（洋梨の先端や、ふくらみの上の火山の火道）へと押し上げます。ポンプが働いていて地殻が封じられていないかぎり、誕生の窓は開いたままです。
  • 火にかけた二つのスープの鍋——厚い泡のふたと薄い泡のふた（大気のふたの原理、A.4 と A.9）：太陽からの距離が、原始惑星系円盤が散る前に各巨大惑星がどれだけの水素とヘリウムを捕らえたかを決めました。土星（9.5 AU）には水の上の熱力学的なふたとして働く厚いガスの外層（質量の 70%〜85%）があります。蒸気は凝縮して内へ落ち戻り、上の層は水で飽和してやわらかいままで、共回転線はその場にとどまり（1.92 R）、放出される衛星は軽く氷に富みます（1,346 kg/m³）。天王星（19 AU）には薄いガスのふた（10%〜20%）しかありません。蒸気は共回転線を通して宇宙へ逃げ、線を 3.24 R へと押し出す角運動量を運び去り、上の放出層を乾かして固めました——だから天王星の衛星はより密なのです（1,505 kg/m³）！
  • 太陽系全体での三つの誕生様式（A.4、L.4）：熱く乾いた内側の縁（地球）では、大きく乾いた月が洋梨の先端に築かれました（構築）。湿った中央の地帯（火星から海王星まで）では、水に富む小さな衛星がふくらみの上の火山から放出されました（放出）。そして冷たく速い外側の縁（冥王星とカロン）では、一つになった天体が「ピーナッツ」へと引き伸ばされ、そのくびれで引き裂かれました（分裂）。
03 · SCIENCE AND MODEL

科学とモデル：誕生の法則、状態の物差し、そして分化の四つの段階（A 部）

論文 11 の A 部は、衛星の法則の精密な定量的条件を定式化します：

  1. 誕生様式の物差し（A.3）：共回転線の半径を親の半径の単位で測ると（x=ac/Rx = a_c / R）、親の半径は完全に打ち消されます！位置 x は自転の速さと平均密度の比だけで決まるので（x3=4πGρ/3Ω2x^3 = 4\pi G\rho / 3\Omega^2）、一つの物差しが宇宙のあらゆる天体に当てはまるのです：
    • 洋梨（洋梨の先端での構築）：x ≈ 2.29（5.77 時間、密度 3,940 kg/m³ の地球——月は親の質量の 1.2% を占める）。
    • ふくらみと火山（ふくらみの上での放出）：x ≈ 1.74〜2.06（7〜9 時間、密度 1,170 kg/m³ の火星、そして同じくガスと氷の巨大惑星——0.01%〜0.02% のごく小さな衛星）。
    • ふくらみのない火山（理論上の可能性）：x ≈ 1.1〜1.5。
    • 完全なピーナッツの分裂（くびれでの分裂）：x ≈ 0.85〜1.02（伸長の閾値 x = 1.53 を越えて引き裂きの閾値 x = 1 へ——1.9〜2.5 時間の冥王星とカロン、カロンは対の質量の 11%）。
  2. 親の分化の段階の年代的な断面としての衛星の組成（A.9）：分化が進むにつれて共回転線は内へ動くので（木星と、土星の生涯の初め）、より遠い衛星はより早く、より近い衛星はより遅く生まれました：
    • 段階 0（分化の始まり——水の遠心力による噴霧）：ロッシュ限界より上の外層からの原始の水の噴霧 →\rightarrow 空気のように軽い氷の衛星（イアペトゥス 1,088 kg/m³、ヒペリオン 544 kg/m³）。
    • 段階 1（初期——混ざった物質）：選別が終わる前の、親全体の組成を代表する物質の放出 →\rightarrow 親の内部の天体に近い密度をもつ大きな衛星（f ≈ 0.6〜0.7：カリスト 1,834、ガニメデ 1,936、タイタン 1,880、チタニア 1,711、オベロン 1,630 kg/m³）。
    • 段階 2（流体力学的なポンプのピーク）：水と軽いケイ酸塩で飽和したマグマの押し出し；揮発性物質の宇宙への逃げ出しが高い孔隙率（「スポンジ状」、30%〜40%）と低い密度を残す →\rightarrow フォボス（1,860）、ダイモス（1,470）、テティス（984）、ミランダ（1,200 kg/m³）。
    • 段階 3（分化の終わり）：はっきりした金属の核をもつ、乾いた密なケイ酸塩の残りの放出 →\rightarrow イオ（3,528 kg/m³）。
正しい密度の比較——内部の天体をガスの外層から切り離す（A.9）

衛星は水素とヘリウムの外層からではなく、内部の天体（岩と氷）から生まれます。衛星の平均密度をケイ酸塩・金属の成分（3,500 kg/m³）と氷の成分（950 kg/m³）に分けると、ケイ酸塩の質量分率 f は、地球（f = 0.98、ρ=3,344\rho = 3,344）から木星（f = 0.83、ρ=2,578\rho = 2,578）、土星（f = 0.36、ρ=1,346\rho = 1,346）へと少しずつ下がり——天王星で上がり戻ります（f = 0.49、ρ=1,505\rho = 1,505）。天王星の薄いガスのふた（10%〜20%）が水を逃がし、上の放出層を乾かしたからです！

04 · THE MECHANISM IN WORDS

言葉で語る仕組み：衛星の法則の十六の条項（A.10）と 13 の点検の手順（B 部）

論文 11 の A.10 部と B 部は、すべての物理的な条件を一つの法則の体系と、太陽系のあらゆる天体のための一つの一様な 13 の点検の測定手順へとまとめます：

  1. 熱力学的な時計としての太陽——誕生の弧（A.10.4 と L.4）：衛星の誕生には、活発な分化、開いた時間の窓、封じられていない地殻、そして粘性の低い地下の層が同時に必要です。太陽からの距離が、四つの条件がどれだけ長くそろっていられるかを決めます。内側の縁（水星と金星）では速い乾燥が誕生の窓を早く閉じ、地球だけが洋梨の先端に一つの月を築くことができました。中央の地帯（火星から土星まで）では衛星がふんだんに放出され、土星でピーク（~ 24 の規則衛星）に達します。そして冷たい外側の縁（天王星、海王星、冥王星）では、地殻の凍結が少しずつポンプの開口をふさぎ、系を力学的な分裂へと移すのです。
  2. 構造の競争と衛星の質量のフィードバック（A.4、A.10.16）：衛星が生まれるには、洋梨やふくらみの放射方向の成長の速さが、共回転線が遠ざかる速さを上回らなければなりません。誕生のあと、衛星と親の質量比が大きければ（地球の月のように 1.2%）、衛星は角運動量の大部分（84%）を運び、親を遅くします。しかし巨大惑星と火星では衛星の質量はごく小さく（0.01%〜0.02%、運動量のわずか 0.4%〜1.4%）、だから共回転線の後退は線を通した水とガスの逃げ出し（ΔLescaped\Delta L_{\mathrm{escaped}}）からだけ来るのです！
  3. 13 の点検の系統的な手順（B 部）：偏りを避けるために、あらゆる惑星と準惑星は年代順の 13 の固定したパラメータで点検されます：（1）全球の基本データ；（2）目録と、規則衛星と捕獲衛星の区別；（3）古代の自転の力学的な復元（点検 3——誕生時の半径と慣性モーメント係数 k を使う！）；（4）誕生の法則の検証；（5）水と揮発性物質の分析；（6）今日の分化の度合い（k = C/MR²）；（7）誕生の窓の定義；（8）潮汐による移動の経路（点検 8——da/dt を積分して、環からの二次的な押しが必要かを見極める）；（9）生存のパラメータ（ロッシュ限界とヒル半径）；（10）親に残る形態的な痕跡；（11）衛星に残る構造的な痕跡（孔隙率、潮汐固定、凍ったふくらみ）；（12）連続した流れとしての環の系の分析；そして（13）異常の切り分け。
05 · THE KEY EQUATIONS

学術的な説明と鍵となる方程式

親の半径を単位とした共回転線の位置（x=ac/Rx = a_c/R）、誕生の日（PbirthP_{\mathrm{birth}}）、そして分化のあいだの内側の縮みと外側のふくらみの効果は、次のように定式化されます（§A.3、§A.5、§B）：

x3=4πGρ3Ω2x^3 = \dfrac{4\pi G\rho}{3\Omega^2}
Pbirth=3πx3GρP_{\mathrm{birth}} = \sqrt{\dfrac{3\pi x^3}{G\rho}}
Pcritical=3πGρ(x=1)P_{\mathrm{critical}} = \sqrt{\dfrac{3\pi}{G\rho}} \quad (x = 1)
L=kMR2Ω=const  ⟹  x∝(k2R)1/3L = kMR^2\Omega = \mathrm{const} \implies x \propto (k^2 R)^{1/3}
rH=a(M3M⊙)1/3r_H = a\left(\dfrac{M}{3M_\odot}\right)^{1/3}

慣性モーメント係数 k は分化の式 x∝(k2R)1/3x \propto (k^2 R)^{1/3} に二乗で現れるので、k が 0.40（均質な天体）から 0.20〜0.25（緻密な核）へ下がると、外側の外層が 1.3 倍ふくらんでも、共回転線 x は 2.10 R から 1.44〜1.68 R へ近づきます——そしてこれこそが、表面と共回転線を引きあわせる地球力学的なエンジンなのです！

06 · THE SIGNATURE

現実に残る署名：共回転線の復元と、衛星の混合の方程式

手順の点検 3 と 5 を惑星に当てはめると、衛星の化学組成と角運動量の保存のあいだの印象的な定量的一致が明らかになります（§A.9、§B）：

  • 衛星の密度の二成分の混合の方程式（§A.9）：式 1ρ=f3500+1−f950\frac{1}{\rho} = \frac{f}{3500} + \frac{1-f}{950} によれば、分化の段階 1 で生まれた大きな衛星のケイ酸塩の質量分率 f は、外側の太陽系全体（カリスト、ガニメデ、タイタン、チタニア、オベロン、そして冥王星とカロンの系も）で f ≈ 0.6〜0.7 の狭く一様な範囲に収束するのです！
  • 質量を失わない共回転線の復元の検証（ΔLescaped=0\Delta L_{\mathrm{escaped}} = 0、B 部）：衛星の角運動量だけを親に戻すと、木星（2.29 R → 2.28 R）と土星（1.92 R → 1.90 R）では線はほとんど動きません（厚いふたの原理と整合）。地球では線は 2.29 R に戻ります（月が運動量の 84% を運ぶので）。一方、火星（6.03 R）、天王星（3.24 R）、海王星（3.39 R）では線は誕生の範囲（x ≈ 2）から遠いままです——三つすべてで、膨大な量の水とガスが共回転線を通して逃げた証拠です！
